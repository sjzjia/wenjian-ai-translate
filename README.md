## 简介

一个 Chrome Manifest V3 扩展。它把网页文本交给**你自己配置的大模型接口**翻译，密钥与译文都留在本地，不经过任何中间服务器。

相比调用浏览器自带翻译，它更适合读技术文档、论文和长文：术语译法可以锁定，原文可以随时对照，滚动加载的新内容会自动补译。

## 功能特性

### 阅读

| 功能 | 说明 |
| --- | --- |
| 全页面翻译 | 按段落分批并发请求，译文逐条流式回填，不必等整批返回 |
| 动态内容翻译 | 翻译完成后继续监听 DOM，滚动加载、展开评论、SPA 路由切换产生的新内容自动补译 |
| 视口优先 | 长页面自动把当前可见段落排到队首，滚到哪译到哪 |
| 悬停翻译 | 按住 `Shift` 把鼠标停在段落上约半秒，直接浮出译文，不打断阅读 |
| 划词翻译 | 选中文字弹出按钮；也可设为选中即译 |
| 段落点译 | `Alt + 点击` 只翻译鼠标所在的那一段，适合长文挑着看 |
| 双语对照 | 保留原文，译文以行内高亮追加在下方，随时对照 |
| 朗读 | 卡片上点「朗读」用系统语音读译文，自动识别中英日韩俄 |
| 外语页面提示 | 打开非系统语言页面时右下角提示，支持按站点忽略 |

### 写作

| 功能 | 说明 |
| --- | --- |
| 输入框翻译 | 在输入框或可编辑区域按 `Alt + Enter` 译成目标语言，再按一次还原 |
| 术语表 | 一行一条 `原文=译文`，强制锁定品牌名、产品名、技术术语的译法 |

### 效率

| 功能 | 说明 |
| --- | --- |
| 译文缓存 | 按「模型 + 语言 + 原文 + 提示词 + 术语表」缓存，重复页面几乎零延迟 |
| 断点续译 | 中途停止保留已译内容，再点翻译只补剩下的，不从头重来 |
| 翻译历史 | 弹窗内可回看最近 60 条划词与段落译文，点击即复制 |
| 用量统计 | 设置页显示累计请求次数与字符数，仅本地统计，可一键清零 |

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Alt + A` | 翻译 / 还原当前页面 |
| `Alt + Enter` | 翻译光标所在输入框，再按一次撤销 |
| `Shift + 悬停` | 翻译鼠标所指段落 |
| `Alt + 点击` | 翻译点击的那一段 |

`Alt + A` 可在 `chrome://extensions/shortcuts` 中改键。

## 安装

1. 下载或克隆本仓库到本地
2. 打开 `chrome://extensions`，右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录
4. 点工具栏图标 → 右上角 ⚙ 进入设置，填写接口信息后点「测试连接」
5. 回到网页，按 `Alt + A` 或点图标里的「翻译整个页面」

> 扩展安装或更新后，**已打开的标签页需要刷新**才能注入 content script。

## 配置

设置页内置 OpenAI、DeepSeek、Moonshot、通义千问、智谱 GLM、本地 Ollama 六家预设，选中后自动填好 Base URL 与常用模型名。

### 接口

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| Base URL | `https://api.openai.com/v1` | 需带版本前缀，插件自动拼接 `/chat/completions` |
| API Key | 空 | 存于 `chrome.storage.sync`，不上传第三方；本地 Ollama 可留空 |
| 模型名称 | `gpt-4o-mini` | 任意兼容模型均可 |
| 关闭思考模式 | 开 | 按接口自动附加关闭参数（Ollama `think:false`、通义 `enable_thinking:false`、智谱 `thinking:disabled`），并清除正文里混入的思考内容；推理模型可关 |
| 温度 | `0.3` | 翻译建议 0.2 ~ 0.4 |

### 翻译行为

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 目标语言 | 简体中文 | 可填任意语言，如「粤语」「文言文」 |
| 双语对照 | 关 | 译文追加在原文下方 |
| 划词自动翻译 | 关 | 开启后选中即译，不显示按钮 |
| 外语页面自动提示 | 开 | 可按站点单独关闭 |
| Shift + 悬停翻译 | 开 | 悬停约 450ms 触发 |
| 输入框翻译 | 开 | `Alt + Enter` 触发 |
| 动态内容翻译 | 开 | 翻译完成后继续监听新增内容 |

### 高级

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| 单批字符数 | `2500` | 越大请求越少，但易被模型截断 |
| 并发请求数 | `6` | 同时发出的批次数。远端 API 默认 6、上限 10；本地模型自动降为 2（服务端串行），填 7 以上可强制调高 |
| 自定义系统提示词 | 空 | 可用 `{lang}` 占位符 |
| 术语表 | 空 | 一行一条 `原文=译文`，最多 300 条 |

> 修改提示词或术语表后，缓存键随之变化，旧译文自动失效，无需手动清缓存。

## 工作原理

```
content script                          background (service worker)
──────────────                          ───────────────────────────
采集可见文本节点
  → 视口内段落优先排序
  → 相同文本去重、按字符数分批
  → 并发 translateStream  ──────────▶   查缓存 → POST /chat/completions（流式）
                                        ◀── 逐条推送 llmtChunk
  → 按编号解析并回填 DOM
  → 翻译完成后启动 MutationObserver
      新增内容 → 采集 → 补译
```

几个关键设计：

- **翻译协议**是纯文本的 `编号|译文` 逐行对应，不用 JSON。模型漏行时能按编号对齐，不会整体错位
- **容错策略**：整批解析后只补缺失的条目，已命中的不重发；一条都没解析到才退回逐条请求
- **首屏优先**：首批最多 200 字符（小页面会更少），剩余文本由其余 worker 均分，保证顶部先出译文，批次数仍是一轮跑完
- **缓存两级**：内存 Map + `storage.local` 持久化，Service Worker 休眠重启不丢
- **密钥隔离**：页面脚本不直接发网络请求，统一由后台发起，避免 CORS 和密钥外泄
- **防重译**：动态翻译会跳过扩展自己插入的 UI 节点，并记录自己写回的文本节点，避免译文被反复翻译

## 项目结构

```
manifest.json          扩展清单（MV3）
background.js          Service Worker：配置、请求、缓存、用量统计、消息路由
content/
  dom.js               文本采集、分批、视口排序、写入译文、还原
  ui.js                划词按钮、译文卡片、朗读、提示条
  main.js              主控：全页翻译、动态补译、悬停、输入框、划词、快捷键
  content.css          注入样式
options/               设置页（接口、翻译行为、高级、术语表、用量）
popup/                 工具栏弹窗（目标语言、双语开关、页面状态、翻译历史）
icons/                 16 / 32 / 48 / 128 图标
```

## 已知限制

- 只处理顶层文档，`iframe` 内的内容不翻译（`all_frames: false`）
- 跳过 `script`、`style`、`code`、`pre`、`input`、`textarea` 等标签，避免破坏代码块与表单
- 纯 URL、邮箱、版本号等无翻译价值的文本会直接跳过以节省 token
- 字符上限：划词 5000、段落点译 3000、输入框 5000
- 点「停止」会立即恢复界面，但已经发出的后台请求仍会跑完，这部分 token 无法回收
- 动态补译每批最多 1500 字符，失败时静默处理，不打断阅读
- 悬停翻译需按住 `Shift`，避免普通阅读时误触发
- 部分推理模型不接受 `temperature` 参数，插件会自动去掉后重试一次

## 常见问题

<details>
<summary><b>提示「当前页面不可用，请刷新后重试」</b></summary>

扩展安装或更新后，已打开的标签页里还没有注入 content script，刷新页面即可。
</details>

<details>
<summary><b>返回 429 或请求频繁失败</b></summary>

把「并发请求数」调到 3 ~ 4，或调小「单批字符数」。
</details>

<details>
<summary><b>译文串行、张冠李戴</b></summary>

多半是自定义系统提示词破坏了「编号|译文」的逐行对应约束，恢复默认提示词即可。
</details>

<details>
<summary><b>译文被截断</b></summary>

模型单次输出长度不够，调小「单批字符数」（建议 2000 ~ 3000）。
</details>

<details>
<summary><b>滚动后新内容没有自动翻译</b></summary>

动态补译需要先完成一次整页翻译，并确保设置页的「动态内容翻译」处于开启状态。
</details>

<details>
<summary><b>按 Alt + Enter 没有反应</b></summary>

光标需在 `input`、`textarea` 或 `contenteditable` 区域内，且「输入框翻译」开关为开启。密码框不处理。
</details>

<details>
<summary><b>术语表填了但译文没变</b></summary>

确认每行都含 `=`，例如 `Transformer=Transformer`。修改后新请求会自动使用新规则，已缓存段落也会失效重译。
</details>

## 隐私

- API Key 仅存于 `chrome.storage.sync`，随 Chrome 账号同步，不经过任何第三方服务器
- 译文缓存与翻译历史存于 `chrome.storage.local`：缓存可在设置页清除，历史可在弹窗中清空
- 页面文本只发送到你配置的 API 地址，扩展本身不收集任何数据
